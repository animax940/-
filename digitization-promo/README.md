# مشروع الرقمنة — إعلان موشن جرافيك (60 ثانية)

إعلان تجاري عربي بأسلوب الرسوم المسطّحة (Flat Motion Graphics)، مبني بالكود ومستوحى من أسلوب فيديو مرجعي.

## المحتوى
| الملف | الوصف |
|---|---|
| `out/digitization_promo_60s.mp4` | الفيديو النهائي 1920×1080، 30 إطاراً/ثانية، صوت AAC بمستوى ‎-14 LUFS (معيار يوتيوب) |
| `index.html` + `anim.js` | المشاهد والرسومات والأيقونات (SVG) والانتقالات، بخط زمني حتمي `render(t)` |
| `tools/render.mjs` | يلتقط الإطارات عبر Chromium ويحوّلها إلى فيديو |
| `tools/tts.py` + `tools/vo.json` | التعليق الصوتي العربي (نص مشكول) عبر Piper/sherpa-onnx |
| `tools/audio.py` | يولّد الموسيقى والمؤثرات الصوتية برمجياً، ويخفض الموسيقى تحت الصوت، ويمزج المسارات |
| `tools/build.sh` | يشغّل خط الإنتاج كاملاً |

## السيناريو
| الوقت | المشهد | التعليق الصوتي |
|---|---|---|
| 0–7.6 | أكوام الأوراق والملفات الضائعة | أكوامٌ من الأوراق، وملفاتٌ ضائعة، ووقتٌ يضيع في البحث |
| 7.6–13.2 | خزانة الأرشيف القديمة | هل ما زالت مؤسستك تعمل بالطريقة القديمة؟ |
| 13.2–21 | ظهور الشعار، ثم الورق ← الماسح ← المنظومة الرقمية | مع مشروع الرقمنة نحوّل أرشيفك الورقي إلى منظومة رقمية ذكية |
| 21–30 | ثلاث خطوات: مسح، فهرسة، سحابة | نمسح الوثائق ضوئياً بدقة عالية، ونفهرسها، ونحفظها في سحابة آمنة |
| 30–36.5 | البحث الفوري على الحاسوب والجوال | ابحث عن أي ملف في ثوانٍ، من أي مكان، وفي أي وقت |
| 36.5–43.7 | الدرع والقفل والصلاحيات | حمايةٌ متكاملة، وصلاحياتٌ دقيقة، ونسخٌ احتياطي مستمر |
| 43.7–51.4 | العدادات وطائرة ورقية | وفّر الوقت والجهد والتكاليف، وانطلق نحو مستقبلٍ بلا ورق |
| 51.4–60 | الخاتمة وبيانات التواصل | مشروع الرقمنة، خطوتك الأولى نحو المستقبل |

## التعديل
- **بيانات التواصل** (`www.example.com` و `+000 000 000 000`) نصوص مؤقتة في `index.html`؛ استبدلها ببياناتك.
- **النصوص والألوان** في `index.html` (متغيرات `:root`) و `anim.js` (الكائن `C`).
- **التعليق الصوتي**: عدّل `tools/vo.json`، ثم شغّل `python3 tools/tts.py tools/vo.json`.

## إعادة البناء
```bash
npm install
pip install sherpa-onnx soundfile numpy scipy
# نموذج الصوت العربي (كريم):
curl -L https://github.com/k2-fsa/sherpa-onnx/releases/download/tts-models/vits-piper-ar_JO-kareem-medium.tar.bz2 | tar xj -C tools
python3 tools/tts.py tools/vo.json
./tools/build.sh
```
للمعاينة الحية في المتصفح افتح `index.html?play`.
